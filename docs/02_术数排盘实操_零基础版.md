# 术数排盘实操详解（零基础版）

说明：本部分为超详细扩展版的简化版，面向零基础读者。每门术数按"准备 → 步骤 → 查表 → 解读 → 完整示例 → 新手提示"结构展开。看完即可上手操作。真实人物默认脱敏。

## 第一篇 · 小六壬（最简单，先学这个）

### 一、准备

你只需要知道三样东西：

- 现在的农历月份（正月=1，二月=2，……十二月=12）
- 今天的农历日期（初一=1，初二=2，……三十=30）
- 现在的时辰（子时=1，丑时=2，……亥时=12）

时辰对照表：

| 时辰 | 时间 | 数字 |
|---|---|---|
| 子时 | 23:00–1:00 | 1 |
| 丑时 | 1:00–3:00 | 2 |
| 寅时 | 3:00–5:00 | 3 |
| 卯时 | 5:00–7:00 | 4 |
| 辰时 | 7:00–9:00 | 5 |
| 巳时 | 9:00–11:00 | 6 |
| 午时 | 11:00–13:00 | 7 |
| 未时 | 13:00–15:00 | 8 |
| 申时 | 15:00–17:00 | 9 |
| 酉时 | 17:00–19:00 | 10 |
| 戌时 | 19:00–21:00 | 11 |
| 亥时 | 21:00–23:00 | 12 |

左手六宫位置（记住这个图）：

```text
        食指    中指    无名指
指尖    留连    速喜    赤口
根部    大安    空亡    小吉
```

### 二、操作步骤

规则：从大安开始，顺时针数。先数月，再数日，再数时辰。落在哪个宫，就是哪个结果。

顺时针顺序：大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡 → 大安 → ……

注意：数到哪个宫，就从哪个宫继续数下一轮。

**举例：农历三月初五午时。**

第一步：数月份——从大安起数1，留连数2，速喜数3。三月落在速喜。

第二步：数日期——从速喜起数1，赤口数2，小吉数3，空亡数4，大安数5。初五落在大安。

第三步：数时辰——从大安起数1，留连数2，速喜数3，赤口数4，小吉数5，空亡数6，大安数7。午时（7）落在大安。

结果：大安。

### 三、六宫解读表

| 宫位 | 五行 | 含义 | 化炼翻译 | 宜 | 忌 |
|---|---|---|---|---|---|
| 大安 | 木 | 安稳、起始、不动 | 木化火起点 | 规划、开始、守成 | 急躁、冒进 |
| 留连 | 水 | 拖延、纠结、反复 | 水化木被堵 | 加火破局、主动 | 等待、拖延 |
| 速喜 | 火 | 迅速、喜事、好消息 | 木已化火火正旺 | 全力出击 | 烧过头 |
| 赤口 | 金 | 口舌、竞争、争执 | 金炼木火炼金 | 接受检验、严谨 | 冲动、口角 |
| 小吉 | 土 | 稳定、收获、顺利 | 火化土土化金沉淀 | 交付、收尾 | 贪多 |
| 空亡 | 无 | 落空、重启、静守 | 系统强制重启 | 停下、静守 | 行动、决策 |

### 四、完整示例

问：今天下午3点去谈一个合作，能成吗？

时间：农历八月十二，申时（15:00–17:00）。

第一步：数月份——大安1→留连2→速喜3→赤口4→小吉5→空亡6→大安7→留连8。八月落在留连。

第二步：数日期——从留连起：留连1→速喜2→赤口3→小吉4→空亡5→大安6→留连7→速喜8→赤口9→小吉10→空亡11→大安12。十二日落在大安。

第三步：数时辰——从大安起：大安1→留连2→速喜3→赤口4→小吉5→空亡6→大安7→留连8→速喜9。申时（9）落在速喜。

结果：速喜。

解读：速喜=迅速、喜事、好消息。合作大概率能成，而且进展快。化炼翻译：木已化火火正旺，全力出击，但防烧过头（别答应太快、别让利太多）。

建议：去谈，主动出击，但保持严谨，别冲昏头。

### 五、新手提示

- 三不占：不诚不占、不义不占、不疑不占。
- 同一件事不要反复占，一天内同一问题只占一次。
- 小六壬只给方向，不给细节。要细节用六爻或梅花。
- 术是辅助，最终决策由你自己做。
- 练习：每天出门前占一次"今天顺利吗"，记录结果，一个月后回看准确率。

## 第二篇 · 八字排盘（最常用，必学）

### 一、准备

你需要知道：

- 出生年月日时（精确到小时）
- 出生地（用于真太阳时修正）
- 性别（定大运顺逆）

工具：万年历（手机App或网站）、真太阳时计算器（网上搜"真太阳时查询"）。

### 二、操作步骤（12步）

**第一步：排年柱**

规则：以立春为界，不是农历正月初一。

查法：出生在当年立春之后 → 用当年干支；出生在当年立春之前 → 用上一年干支。立春时间：每年2月3–5日之间，具体查万年历。

例子：1996年2月4日立春。2月4日之后出生=丙子年；2月4日之前出生=乙亥年。

规则：以节令为界（不是农历初一）。

| 月 | 节令 | 大约日期 |

月支固定：正月=寅，二月=卯，三月=辰，四月=巳，五月=午，六月=未，七月=申，八月=酉，九月=戌，十月=亥，十一月=子，十二月=丑。

月干用五虎遁（根据年干推月干）：

```text
甲己之年丙作首 → 甲年或己年，正月为丙寅
乙庚之岁戊为头 → 乙年或庚年，正月为戊寅
丙辛必定寻庚起 → 丙年或辛年，正月为庚寅
丁壬壬位顺行流 → 丁年或壬年，正月为壬寅
戊癸何方发，甲寅之上好追求 → 戊年或癸年，正月为甲寅
```

例子：丙子年，三月。丙年 → 正月庚寅，二月辛卯，三月壬辰。所以月柱=壬辰。

**第三步：排日柱**

规则：查万年历，直接查当天的干支。注意子时换日：23:00后算次日。

例子：1996年8月28日，查万年历=丁酉日。

**第四步：排时柱**

规则：用五鼠遁（根据日干推时干）。

```text
甲己还加甲 → 甲日或己日，子时为甲子
乙庚丙作初 → 乙日或庚日，子时为丙子
丙辛从戊起 → 丙日或辛日，子时为戊子
丁壬庚子居 → 丁日或壬日，子时为庚子
戊癸何方发，壬子是真途 → 戊日或癸日，子时为壬子
```

时辰地支固定：子1、丑2、寅3、卯4、辰5、巳6、午7、未8、申9、酉10、戌11、亥12。

例子：丁酉日，未时（13:00–15:00）。丁日 → 子时庚子，丑时辛丑，寅时壬寅，卯时癸卯，辰时甲辰，巳时乙巳，午时丙午，未时丁未。所以时柱=丁未。

**第五步：排出四柱**

例子汇总：1996年8月28日未时。

```text
年柱：丙子
月柱：壬辰（注：此处示例月份与实际不符，仅作演示）
日柱：丁酉
时柱：丁未
```

正确示例（1996年8月28日未时，实际为丙申月）：

```text
年柱：丙子
月柱：丙申
日柱：丁酉
时柱：丁未
```

**第六步：标日主**

日主=日干。例子中日干=丁，所以日主=丁火。

**第七步：排十神**

例子：子藏癸；申藏庚壬戊；酉藏辛；未藏己丁乙。

**第九步：定旺衰**

旺相休囚死（以月令为准）：

| 季节 | 旺 | 相 | 休 | 囚 | 死 |
|---|---|---|---|---|---|
| 春（寅卯月） | 木 | 火 | 水 | 金 | 土 |
| 夏（巳午月） | 火 | 土 | 木 | 水 | 金 |
| 秋（申酉月） | 金 | 水 | 土 | 火 | 木 |
| 冬（亥子月） | 水 | 木 | 金 | 土 | 火 |
| 四季（辰未戌丑月） | 土 | 金 | 火 | 木 | 水 |

例子：日主丁火，月令申（秋）。火在秋=囚。所以丁火偏弱。

**第十步：定身强身弱**

三看：得时（月令生扶日主）、得地（地支有日主的禄、刃、根）、得势（天干有比劫帮扶）。

例子：丁火日主。

- 得时？月令申金，金克火，不得时。
- 得地？日支酉金，不得地。时支未藏丁，有根。
- 得势？年干丙、月干丙、时干丁，三个火帮身，得势。

综合：不得时、不得地、得势。身弱偏中。

**第十一步：取喜用神**

- 身强：用克泄耗（官杀、食伤、财星）
- 身弱：用生扶（印星、比劫）

例子：丁火身弱偏中，火多但无根。喜用：木（印，生火）、土（食伤，泄火但需平衡）；忌神：金（财，耗火）、水（官杀，克火）。

**第十二步：排大运**

规则：阳男阴女顺行；阴男阳女逆行。起运岁数：从出生日到下一个节令（顺行）或上一个节令（逆行）的天数÷3。

例子：丙子年（阳年），男命=阳男=顺行。

### 三、解读要点

| 看什么 | 怎么看 |
|---|---|
| 日主强弱 | 得时/得地/得势 |
| 喜用忌神 | 身强用克泄耗，身弱用生扶 |
| 十神格局 | 看哪个十神最旺 |
| 大运流年 | 喜用神运吉，忌神运凶 |
| 人生功课 | 五行链路哪环断裂 |

### 四、完整示例

八字：丙子 丙申 丁酉 丁未

日主：丁火（灯烛）

分析：

- 火多（三丙一丁），但无根（地支子申酉未中，火根弱）
- 金旺（申酉），财星强
- 木弱（无木），印星弱
- 土弱（未中有己土），食伤弱
- 身强身弱：火多但无根，身弱偏中。
- 喜用：木（印）、土（食伤）；忌神：金（财）、水（官杀）
- 人生功课：筑土（补食伤，输出）+ 护金（补财，理财）
- 化炼卡点：火化土（输出）和土化金（变现）链条断裂。

### 五、新手提示

- 必须用真太阳时：出生地经度每差1度，时间差4分钟。
- 子时换日：23:00后算次日。
- 节气精确到时辰：月柱以节令交接时刻为界。
- 不要只看日主：要看全局。
- 喜用神不是缺什么补什么：补对不补缺。
- 练习：先排自己的八字，再排家人朋友的，排10个就有手感了。

## 第三篇 · 六爻纳甲（问事最常用）

### 一、准备

你需要：三枚铜钱（或硬币）、一支笔、一张纸、一个明确的问题。

问题要求：具体（"这次面试能过吗"而不是"我今年运势如何"）；一事一占；不占生死、他人隐私、戏占。

### 二、起卦步骤

摇卦法：双手合扣三枚铜钱，默念问题，摇动后掷出，记录结果，重复6次，从下往上记。

记录规则：

| 结果 | 名称 | 符号 | 阴阳 |
|---|---|---|---|
| 一背二字 | 单 | — | 阳 |
| 二背一字 | 拆 | - - | 阴 |
| 三背 | 重 | —○ | 老阳（变阴） |
| 三字 | 交 | - -× | 老阴（变阳） |

注意：背=背面，字=正面。不同铜钱定义不同，摇之前先定好。

### 四、断卦步骤

**第一步：定用神**

| 问什么 | 用神 |
|---|---|
| 财运 | 妻财 |
| 事业/官运 | 官鬼 |
| 父母/长辈/房子 | 父母 |
| 子女/下属 | 子孙 |
| 兄弟/朋友 | 兄弟 |

**第二步：看用神旺衰**

- 用神旺相（得月建日辰生扶）=吉
- 用神受克（被月建日辰克制）=凶

**第三步：看世应关系**

- 世生应=我付出；应生世=对方帮我
- 世克应=我主动；应克世=对方压制
- 世应比和=平等

**第四步：看动爻**

- 动爻生用神=吉；动爻克用神=凶
- 动爻生世=有助力；动爻克世=有阻力

**第五步：看月建日辰**

- 月建=当月地支，管一月；日辰=当日地支，管一日
- 月建日辰生用神=吉；月建日辰克用神=凶

### 五、完整示例

问：这次面试能过吗？

起卦（假设结果）：初爻单、二爻拆、三爻单、四爻拆、五爻单、六爻拆。

卦象：从下往上=阳阴阳阴阳阴=离卦。

## 第四篇 · 梅花易数（快速占断）

### 一、准备

你只需要：一个明确的问题、当下的时间或看到的数字。核心：万物皆可起卦，数字、声音、方位、时间都行。

### 二、起卦步骤

**方法一：时间起卦（最常用）**

公式：

- 上卦 =（年支数+月+日）÷8，取余数
- 下卦 =（年支数+月+日+时）÷8，取余数
- 动爻 =（年支数+月+日+时）÷6，取余数

年支数：子1、丑2、寅3、卯4、辰5、巳6、午7、未8、申9、酉10、戌11、亥12。

先天卦数：乾1、兑2、离3、震4、巽5、坎6、艮7、坤8。

余数对应：余1=乾，余2=兑，余3=离，余4=震，余5=巽，余6=坎，余7=艮，余0=坤。

**方法二：数字起卦**

报两个数字：第一个数÷8=上卦；第二个数÷8=下卦；两数之和÷6=动爻。

**方法三：物数起卦**

看到什么东西，数它的数量，按数字起卦。

### 三、定卦步骤

第一步：确定本卦（上卦+下卦）。

第二步：定互卦——本卦去掉初爻和上爻，中间四爻分作两卦。例：本卦=上离下震。六爻：上爻、五爻、四爻、三爻、二爻、初爻。互卦：取五、四、三爻为上卦；四、三、二爻为下卦。

第三步：定变卦——动爻变阴阳（阳变阴，阴变阳）。

第四步：分体用——动爻所在卦为用，另一卦为体。

### 四、断卦步骤

核心：体用生克

| 关系 | 吉凶 |
|---|---|
| 用生体 | 吉（有进益） |
| 体用比和 | 吉（顺利） |
| 体克用 | 吉（诸事可成） |
| 体生用 | 小凶（有耗失） |
| 用克体 | 凶（诸事不成） |

看互卦：互卦=中间过程。看变卦：变卦=最终结果。

### 五、完整示例

问：明天谈合作顺利吗？

时间：农历八月十二午时。年支数：假设当年为子年=1。

计算：

- 上卦 =（1+8+12）÷8 = 21÷8 = 2余5 → 巽
- 下卦 =（1+8+12+7）÷8 = 28÷8 = 3余4 → 震
- 动爻 = 28÷6 = 4余4 → 四爻动

本卦：上巽下震 = 风雷益。互卦：取五、四、三爻=上卦；四、三、二爻=下卦。变卦：四爻动，阳变阴。体用：四爻在上卦（巽），所以用=巽，体=震。

断卦：体=震木，用=巽木，体用比和=吉。互卦看过程。变卦看结果。结论：比和=顺利，合作大概率能成。

### 六、新手提示

- 不动不占，不因事不占。
- 数说当也，必以理论之而后备。
- 体用生克是核心，互卦变卦是辅助。
- 三要十应：耳听、目视、心思，结合外应。
- 练习：每天用时间起卦占一次，验证准确率。
