## 一、核心理论：玄同理论 V3.10 整合版

### 1.1 总纲

道法术器势德：体道于心是谓德，循道立法是谓《五行历》，因法施术是谓断卦与识人，以器载术是谓纳甲与罗盘，积术成势是谓能力与财富，以德御势是谓内圣外王，万法归宗是谓玄同。

### 1.2 三大根本重定义

| 概念 | 定义 |
|---|---|
| 五行 | 非物乃力：水=静藏、木=生发、火=发散、土=转化、金=收敛 |
| 相生 | 化：形态彻底消亡与重生（木化火→火化土→土化金→金化水→水化木） |
| 相克 | 炼：系统内质检提纯（金炼木/木炼土/土炼水/水炼火/火炼金）；炼过头为反克 |

### 1.3 阴阳修补

- 化有阴阳：阳化=顺序显形，阴化=逆序归真。
- 炼有阴阳：阳炼=提纯成长，阴克=毁灭破坏；判据=内核火种变旺还是熄灭。
- 总纲：孤阴不生，孤阳不长。信受阴尺，奉行阳尺。

### 1.4 五行历（时间操作系统）

- 年度五季：木季 2.4–4.17 布局 / 火季 4.18–6.28 流量 / 土季 6.29–9.8 交付 / 金季 9.9–11.18 回收 / 水季 11.19–立春 储备。
- 日课五时：木时晨起写 3 目标 / 火时 9–11 点对外输出 / 土时 14–17 点深度交付 / 金时睡前记账复盘 / 水时焦躁即独处。
- 三铁律：时间是力量的载体、记录就是纳甲、纪律就是金生水。

### 1.5 纳甲数据库

- 化炼事件复盘卡：日期时辰 / 事件 / 化炼判断 / 阴阳双尺 / 决策 / 复验。
- 三大铁用：补火化土漏洞、成为自己的老师、让五行历长出眼睛。

### 1.6 阴阳双尺

- 阴尺：内观数据（情绪复盘、化炼日志、卦例、梦境直觉）。
- 阳尺：外观数据（金钱数字、量化指标、生理指标、他人反馈）。
- 阴阳相符则为验，不符则为警。

### 1.7 人生五境

木境谋者（点火）→ 火境行者（沉淀）→ 土境守者（提炼）→ 金境成者（放下）→ 水境化者（重启）。

### 1.8 术数工具箱（19 项）

小六壬、梅花、六爻、八字、风水、奇门、紫微、七政四余、大六壬、太乙、相术、择日、塔罗、内丹、符箓法术、祝由术、易筋经、神煞、纳音。

### 1.9 应用八领域

搞钱、情感、身体、情绪、学习、人际关系、财务管理、修行与内证。

### 1.10 心法

玄同十二纲（冲气为和、序成有阶等）、以德御势五重转化（谦=金化水、信=土化金、仁=木化火、义=火炼金、智=水炼火）、九宫决策矩阵、混沌三原则。
