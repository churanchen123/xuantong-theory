### 二、左手六宫位置（必须记牢）

```text
        食指      中指      无名指
指尖    留连      速喜      赤口
根部    大安      空亡      小吉
```

顺时针顺序：大安→留连→速喜→赤口→小吉→空亡→大安→……

记忆口诀：大安起，顺数走；月日时，三段数；落哪宫，看结果。

### 三、操作步骤（三段数）

核心规则：从大安起，先数月，再数日，再数时辰。每段从上一段的落点继续数。

- 第一段：数月——从大安起数1，顺时针数到农历月数。
- 第二段：数日——从月落宫起数1，顺时针数到农历日期。
- 第三段：数时辰——从日落宫起数1，顺时针数到时辰数。

最终落宫=结果。

### 五、完整示例（3个）

**示例1：问合作**

时间：农历八月十二申时。

第一步：数月——大安1→留连2→速喜3→赤口4→小吉5→空亡6→大安7→留连8。八月落留连。

第二步：数日——留连1→速喜2→赤口3→小吉4→空亡5→大安6→留连7→速喜8→赤口9→小吉10→空亡11→大安12。十二日落大安。

第三步：数时辰——大安1→留连2→速喜3→赤口4→小吉5→空亡6→大安7→留连8→速喜9。申时（9）落速喜。

结果：速喜。解读：合作顺利，进展快。但防烧过头（别答应太快、别让利太多）。

**示例2：问出行**

时间：农历三月初五午时。

第一步：数月——大安1→留连2→速喜3。三月落速喜。

第二步：数日——速喜1→赤口2→小吉3→空亡4→大安5。初五落大安。

第三步：数时辰——大安1→留连2→速喜3→赤口4→小吉5→空亡6→大安7。午时（7）落大安。

结果：大安。解读：出行平安，平稳无事。宜静不宜动。

**示例3：问感情**

时间：农历七月十五亥时。

第一步：数月——大安1→留连2→速喜3→赤口4→小吉5→空亡6→大安7。七月落大安。

第二步：数日——大安1→留连2→速喜3→赤口4→小吉5→空亡6→大安7→留连8→速喜9→赤口10→小吉11→空亡12→大安13→留连14→速喜15。十五日落速喜。

第三步：数时辰——速喜1→赤口2→小吉3→空亡4→大安5→留连6→速喜7→赤口8→小吉9→空亡10→大安11→留连12。亥时（12）落留连。

结果：留连。解读：感情纠缠，需主动沟通。加火破局。

### 六、常见错误

| 错误 | 纠正 |
|---|---|
| 用公历月日 | 必须用农历 |
| 从大安重新数 | 每段从上一段落点继续数 |
| 逆时针数 | 必须顺时针 |
| 数错起点 | 第一段从大安起，第二段从月落宫起，第三段从日落宫起 |
| 反复占同一事 | 一天内同一问题只占一次 |
| 时辰算错 | 23:00后算子时，属次日 |

### 七、新手练习

- 第一周：每天出门前占"今天顺利吗"，记录结果。
- 第二周：占具体事（今天会下雨吗、今天有好事吗）。
- 第三周：回看准确率，调整判断。
- 第四周：尝试占重要事（合作、出行、感情）。

### 二、真太阳时修正

为什么：北京时间是全国统一时间，但各地经度不同，实际太阳时不同。

公式：真太阳时=北京时间+（当地经度-120°）×4分钟

例子：郑州经度约113.6°。修正=（113.6-120）×4=-25.6分钟。北京时间12:00→真太阳时11:34。

注意：差几分钟可能改变时柱，必须修正。

### 四、完整示例

八字：丙子 丙申 丁酉 丁未

日主：丁火（灯烛）

十神：

```text
年柱 丙子：劫财 + 七杀
月柱 丙申：劫财 + 偏财
日柱 丁酉：日主 + 偏财
时柱 丁未：比肩 + 食神
```

藏干：子藏癸；申藏庚壬戊；酉藏辛；未藏己丁乙。

旺衰：月令申（秋），火囚。

### 二、起卦步骤

**方法一：时间起卦**

公式：

- 上卦=（年支数+月+日）÷8，取余数
- 下卦=（年支数+月+日+时）÷8，取余数
- 动爻=（年支数+月+日+时）÷6，取余数

年支数：子1、丑2、寅3、卯4、辰5、巳6、午7、未8、申9、酉10、戌11、亥12。

**方法二：数字起卦**

报两个数字：第一个数÷8=上卦；第二个数÷8=下卦；两数之和÷6=动爻。

**方法三：物数起卦**

看到什么东西，数它的数量。

### 三、定卦步骤

第一步：确定本卦（上卦+下卦）。

第二步：定互卦——本卦去掉初爻和上爻，中间四爻分作两卦。

第三步：定变卦——动爻变阴阳。

第四步：分体用——动爻所在卦为用，另一卦为体。

### 四、断卦步骤

核心：体用生克

| 关系 | 吉凶 |
|---|---|
| 用生体 | 吉 |
| 体用比和 | 吉 |
| 体克用 | 吉 |
| 体生用 | 小凶 |
| 用克体 | 凶 |

看互卦：互卦=中间过程。看变卦：变卦=最终结果。
